# 4Noobs (He4rt)

## Problema

A comunidade He4rt Developers mantém repositórios educativos ("4Noobs") espalhados no GitHub, difíceis de descobrir.

## O que faz

Organiza os repositórios 4Noobs por categoria (linguagens, frameworks, ferramentas, banco de dados, sistemas operacionais, design, paradigmas, certificações, diversos), com link para cada um.

## O que não faz

- Não busca os repositórios em runtime pela API do GitHub. A lista é MDX curado.

## Onde está

`src/data/content/4noobs/*.mdx`, `src/pages/4noobs/`.
