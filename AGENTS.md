# QueroProgramar — instruções para agentes

## Contexto de produto

Este repo usa product.md. No início de toda sessão, leia:

- `.product/STRATEGY.md` — visão, posicionamento, público
- `.product/ROADMAP.md` — marcos do trimestre
- `.product/CONTEXT.md` — restrições de arquitetura, decisões
- `.product/specs/` — specs de feature (leia as que tocam a tarefa)

Confira sempre o `status` no frontmatter da spec antes de implementar.

## Guidelines

Leia e siga sempre estes arquivos:

- @.ai/guidelines/general.md
- @.ai/guidelines/domain/01-docs-de-dominio.md
- @.ai/guidelines/presentation/01-estrutura.md
- @.ai/guidelines/workflow/01-commits-e-branches.md

## Rules por caminho

Antes de planejar ou editar um arquivo, abra `.ai/rules/index.md`, ache as linhas cujos globs batem com o caminho e leia aquelas rules.
